Microwave Beep — one original funny line about everyday kitchen life for make.fun's "The One-Line Laugh" bounty ($5 in USDC). `main.ts` (pure Node.js stdlib, no dependencies, fully deterministic) writes a single vivid scene to `entry.txt`: the microwave beeps at 2 a.m. like it just finished a double shift, and you stand in the dark waiting for the second beep like your boss is calling you back to work — the twist lands on the last word.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes one line (161 characters, no trailing newline) to `./output/entry.txt`.
